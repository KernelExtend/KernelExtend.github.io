爪爪特性喵 🐾 ​

本喵专为极客主人打造，涵盖了执行引擎、流式缓冲、文件百宝箱与个性化毛色的全方位体验喵~

⚡ 1. 双模原生狂奔与环境装载喵 ​

  • 支持格式：本喵原生支持 Linux Shell 脚本（.sh）与 ELF 原生可执行二进制（.so）喵。
  • 贴心环境注入：任务出发前，本喵自动备齐标准 Linux 工具包，防止找不到命令迷路喵：
    bash
    export PATH=/sbin:/system/sbin:/system/bin:/system/xbin:$PATH
export TERM=xterm-256color
export LANG=en_US.UTF-8
  • 权限拉满：执行前本喵会自动念出 chmod 777 咒语赋予最高爪权，绝不让权限绊住主人的脚步喵！
  • 行踪掌握：本喵会牢牢看住子进程的原生 PID 与返回的退出码（Exit Code）喵。

🐟 2. 16ms 小鱼干批处理与防撑爆保护喵 ​

  • 16ms 顺滑调度：面对像暴风雨一样涌来的海量日志，日志会先进入本喵的爪爪小队列，每 16ms（约 60 帧）统一呈递给主人，保证页面顺滑如撸猫一样丝滑喵~
  • 滑动窗口防撑爆：控制台字数上限为 250,000 字符喵。一旦超过，本喵会自动顺着换行符截取保留最新的 180,000 字符，内存平平稳稳，绝不发生 OOM 翻车事故喵！
  • 彩色毛线球着色：内置 ANSI 状态解析机，支持标准 16 色与加粗高亮渲染，把输出变得五彩斑斓喵~

📦 3. 全盘 ROOT 文件百宝箱喵 ​

  • 直通核心秘密基地：默认大本营在 /data/adb/KernelEX，适配主流 Magisk / KSU / APatch 玩法喵。
  • 独立小窝隔离存储：开启「使用独立文件夹存储」后，添加脚本时本喵会自动搭建带时间戳的专属小窝，防止多个脚本同名文件打架冲突喵！
  • 字体实时试戴与一键换装：在文件页点击任何 .ttf / .otf 字体，主人都可以实时敲字预览效果，还能一键换成整个软件的全局字体喵！
  • 安全防爪滑注入：底层 Shell 执行路径全量单引号转义（replace("'", "'\\''")），重命名过滤 .. 与古怪符号，安全防范拉满喵~

🎨 4. MIUIX 质感与五彩斑斓调色盘喵 ​

  • 双套好看毛色：在「设置」中主人可以自由切换 MIUIX (HyperOS 晶莹通透质感) 或 Material 3 风格喵。
  • 悬浮肉垫 Dock 栏：MIUIX 模式下可开启悬浮胶囊底栏，搭配软糯弹牙的 Spring 弹簧动效喵！
  • HSV 调色盘：内置 16 款极客预设配色（荧光绿、黑客绿、赛博青、电光蓝等），主人可以随意滑动色相环和明暗滑块，定制专属终端文字颜色喵~
