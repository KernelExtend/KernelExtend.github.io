喵爪雷达

快速抓起喵 🐾 ​

欢迎主人来到 KernelEX 喵！本喵会一步步带领主人了解猫窝环境要求、授权流程，以及怎样运行主人的第一个脚本喵~

📱 猫窝运行环境要求喵 ​

在开始之前，请主人确认设备满足以下条件喵：

  • 系统版本：Android 8.0 (API 26) 及以上喵
  • 设备架构：arm64-v8a、armeabi-v7a、x86_64 都支持喵
  • ROOT 方案：已经安装好 Magisk、KernelSU 或 APatch 超级大管家喵
  • 存储权限：Android 11+ 设备需要给本喵「管理所有文件」权限，方便本喵帮主人读取外部存储里的脚本喵~

🔑 权限配置指引喵 ​

主人第一次抱起 KernelEX 时，会看到可爱的**权限检查门（Permission Gate）**喵：

  1. ROOT 超级权限：主人点击「请求 ROOT 授权」，在大管家（Magisk/KernelSU/APatch）弹窗里选择「永久允许」即可喵！
  2. 所有文件管理权限：主人点击前往系统设置，开启文件管理开关，本喵就能帮主人找到藏在手机各处的脚本喵~
  3. 忽略电池优化（本喵强烈推荐开启）：申请加入系统白名单，这样即使主人把手机塞进口袋，后台任务也不会被无情查杀喵！

自动感知喵

当所有必要权限都备齐之后，本喵就会自动感知并带主人进入主界面，完全不需要主人费心反复手动刷新喵~

🚀 运行主人的第一个脚本喵 ​

本喵为主人准备了三种超级方便的执行姿势喵：

姿势 1：首页直接输入或挑选喵 ​

  1. 进入底栏「主页」喵；
  2. 在输入框填入脚本绝对路径，或者点击「从文件管理器选择」挑出 .sh 或 .so 目标文件喵；
  3. 点击「立即执行」，本喵就会立刻跳到「终端」把运行日志一条条递给主人看喵！

姿势 2：工作区秘密基地一键启动喵 ​

  1. 把脚本直接丢进本喵的默认工作区：/data/adb/KernelEX/ 喵；
  2. 在「主页」下方的小卡片里，主人轻轻一点就能直接选定或启动喵~

姿势 3：全盘文件页长按收纳喵 ​

  1. 切换到底栏「文件」页面喵；
  2. 找到目标脚本，长按它呼出爪爪菜单喵；
  3. 选择「添加到 KernelEX」，本喵会自动复制到工作区并加上 chmod 777 满权喵（如果在设置开启了「添加后自动执行」，还会立即为主人跑起来喵）！

💻 终端操作与互动喵 ​

在「终端」页面，主人可以对本喵下达这些指令喵：

  • 投喂输入（stdin）：如果脚本在等待主人回答输入，主人在底部输入栏打字并点击「发送」就可以投喂给它喵~
  • 轻挠中断（Ctrl+C）：点击「中断」按钮，本喵会给正在奔跑的子进程发送 SIGINT（kill -2）打断信号喵！
  • 强力按倒（结束进程）：点击「结束进程」强行拍灭顽固卡死任务（kill -9）喵。
  • 打包复制：点击顶部「复制输出」一键把控制台日志复制进主人的剪贴板喵。
  • 拍拍清屏与再跑一次：点击「清屏」把终端擦得干干净净，或者点「重新运行」让本喵再为主人跑一次上次的任务喵~
