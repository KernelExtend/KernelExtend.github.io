快速開始 ​

歡迎使用 KernelEX！本章節將帶你快速瞭解環境要求、安裝授權流程以及如何執行你的第一個腳本。

📱 運行環境要求 ​

在開始使用前，請確保你的 Android 裝置滿足以下條件：

  • 作業系統：Android 8.0 (API 26) 及以上
  • 裝置架構：arm64-v8a、armeabi-v7a、x86_64
  • ROOT 方案：已安裝並啟用 Magisk、KernelSU 或 APatch 超級使用者管理器
  • 儲存權限：Android 11+ 裝置需授予「管理所有檔案」權限（用於讀取/匯入外部儲存腳本）

🔑 權限設定指引 ​

首次開啟 KernelEX 時，應用將進入**權限檢查門（Permission Gate）**引導介面：

  1. ROOT 超級使用者權限：點擊「請求 ROOT 授權」，在彈出的授權管理器（Magisk/KernelSU/APatch）中點擊「永久允許」。
  2. 所有檔案存取權限：點擊前往系統設定，開啟「授予所有檔案管理權限」，以便應用讀取外部儲存中的腳本。
  3. 忽略電池最佳化（建議開啟）：點擊申請加入系統電池白名單，防止後台長時間執行繁重腳本時被系統行程清理。

自動感知

所有必要權限就緒後，頁面將自動感知並進入軟體主介面，無需反覆手動重新整理。

🚀 執行你的第一個腳本 ​

KernelEX 提供多種便捷的檔案執行方式：

方式 1：首頁路徑輸入與選擇 ​

  1. 開啟應用，進入底欄「首頁」；
  2. 在輸入框直接輸入腳本絕對路徑，或點擊「從檔案管理器選擇」挑選 .sh 或 .so 檔案；
  3. 點擊「立即執行」，應用將自動跳轉到「終端」頁面並即時列印輸出。

方式 2：工作區目錄一鍵執行 ​

  1. 將你的腳本或可執行檔案放入預設工作區目錄：/data/adb/KernelEX/；
  2. 在「首頁」下方卡片中點擊對應檔案即可直接選定或啟動。

方式 3：全盤檔案管理器長按新增 ​

  1. 切換至底欄「檔案」頁面；
  2. 瀏覽至腳本所在目錄，長按目標檔案呼出操作選單；
  3. 選擇「新增到 KernelEX」，檔案將自動複製到工作區並自動設定 chmod 777 權限（若在設定中開啟了「新增後自動執行」，將立即開始運行）。

💻 終端操作與控制 ​

進入「終端」頁面後，你可以進行以下操作：

  • 傳送標準輸入（stdin）：如果腳本在等待使用者互動輸入（例如 read -p "請輸入: "），在底部輸入框輸入內容並點擊「傳送」或換行鍵即可。
  • 傳送中斷訊號（Ctrl+C）：點擊「中斷」按鈕向當前運行中的子行程傳送 SIGINT（kill -2）訊號。
  • 強制結束任務：點擊「結束行程」按鈕強行終止任務（kill -9）。
  • 複製輸出：點擊頂部「複製輸出」一鍵複製控制台純文字日誌到剪貼簿。
  • 清屏與重跑：任務結束後點擊「清屏」重設控制台，或點擊「重新運行」再次執行上次任務。
