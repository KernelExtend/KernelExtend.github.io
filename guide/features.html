核心功能 ​

KernelEX 为 Android 底层极客与脚本开发者量身打造，涵盖了执行引擎、流式缓冲、文件管理与个性化界面的全方位体验。

⚡ 1. 原生双模执行与环境装载 ​

  • 支持格式：原生支持 Linux Shell 脚本（.sh）与 ELF 二进制可执行文件（.so）。
  • 标准环境变量注入：任务启动时自动预置核心路径，避免因找不到系统命令而报错：
    bash
    export PATH=/sbin:/system/sbin:/system/bin:/system/xbin:$PATH
export TERM=xterm-256color
export LANG=en_US.UTF-8
  • 权限自动化：执行前自动调用 chmod 777 赋予满权，确保无执行权限障碍。
  • 生命周期跟踪：精确监控进程原生 PID 与返回的退出码（Exit Code）。

🌊 2. 16ms 批处理流控与内存保护 ​

  • 16ms 帧同步防抖：针对产生海量高频日志的脚本（如编译输出、抓包抓日志、刷写过程），日志先进入并发队列，按 16ms 周期聚合刷新，避免 Compose 频繁 Recomposition 导致的掉帧卡顿。
  • 滑动窗口内存熔断：控制台文本上限设为 250,000 字符。超出时自动以换行符为界滑动截取后 180,000 字符，内存平稳恒定，杜绝长任务 OOM。
  • ANSI 文本着色：内置正则与状态解析机，支持标准 16 色与加粗高亮渲染。

📁 3. 全盘 ROOT 文件管理 ​

  • 直通核心工作区：默认工作目录设在 /data/adb/KernelEX，适配主流 Magisk / KSU / APatch 工作流。
  • 独立文件夹存储隔离：开启「使用独立文件夹存储」后，添加脚本时会自动创建带时间戳的专属子文件夹，防止多个同名脚本或依赖资源互相覆盖冲突。
  • 字体文件预览与热替换：在文件管理器中点击任意 .ttf / .otf 文件即可实时预览字体效果，支持一键设置为全局软件字体。
  • 安全防注入防护：底层 Shell 执行路径全量单引号转义（replace("'", "'\\''")），重命名过滤 .. 与特殊分隔符，防止路径穿越。

🎨 4. MIUIX 质感与个性化系统 ​

  • 双主题支持：在「设置」中可自由选择 MIUIX (HyperOS 拟物与通透质感) 或 Material 3 设计语言。
  • 悬浮 Dock 栏：MIUIX 模式下可开启底栏悬浮胶囊样式，搭配流畅的 Spring 弹簧动效。
  • HSV 调色盘：内置 16 种极客预设配色（荧光绿、黑客绿、赛博青、电光蓝等），支持滑动色相环与明暗滑块精确调节终端文字色彩。
