快速开始 ​

欢迎使用 KernelEX！本章节将带你快速了解环境要求、安装授权流程以及如何执行你的第一个脚本。

📱 运行环境要求 ​

在开始使用前，请确保你的 Android 设备满足以下条件：

  • 操作系统：Android 8.0 (API 26) 及以上
  • 设备架构：arm64-v8a、armeabi-v7a、x86_64
  • ROOT 方案：已安装并激活 Magisk、KernelSU 或 APatch 超级用户管理器
  • 存储权限：Android 11+ 设备需授予「管理所有文件」权限（用于读取/导入外部存储脚本）

🔑 权限配置指引 ​

首次打开 KernelEX 时，应用将进入**权限检查门（Permission Gate）**引导界面：

  1. ROOT 超级用户权限：点击「请求 ROOT 授权」，在弹出的授权管理器（Magisk/KernelSU/APatch）中点击「永久允许」。
  2. 所有文件访问权限：点击前往系统设置，开启「授予所有文件管理权限」，以便应用读取外部存储中的脚本。
  3. 忽略电池优化（推荐开启）：点击申请加入系统电池白名单，防止后台长时间执行繁重脚本时被系统进程查杀。

自动感知

所有必要权限就绪后，页面将自动感知并进入软件主界面，无需反复手动刷新。

🚀 执行你的第一个脚本 ​

KernelEX 提供多种便捷的文件执行方式：

方式 1：主页路径输入与选择 ​

  1. 打开应用，进入底栏「主页」；
  2. 在输入框直接输入脚本绝对路径，或点击「从文件管理器选择」挑选 .sh 或 .so 文件；
  3. 点击「立即执行」，应用将自动跳转到「终端」页面并实时打印输出。

方式 2：工作区目录一键执行 ​

  1. 将你的脚本或可执行文件放入默认工作区目录：/data/adb/KernelEX/；
  2. 在「主页」下方卡片中点击对应文件即可直接选定或启动。

方式 3：全盘文件管理器长按添加 ​

  1. 切换至底栏「文件」页面；
  2. 浏览至脚本所在目录，长按目标文件呼出操作菜单；
  3. 选择「添加到 KernelEX」，文件将自动复制到工作区并自动设置 chmod 777 权限（若在设置中开启了「添加后自动执行」，将立即开始运行）。

💻 终端操作与控制 ​

进入「终端」页面后，你可以进行以下操作：

  • 发送标准输入（stdin）：如果脚本在等待用户交互输入（例如 read -p "请输入: "），在底部输入框输入内容并点击「发送」或回车即可。
  • 发送中断信号（Ctrl+C）：点击「中断」按钮向当前运行中的子进程发送 SIGINT（kill -2）信号。
  • 强制结束任务：点击「结束进程」按钮强行终止任务（kill -9）。
  • 复制输出：点击顶部「复制输出」一键复制控制台纯文本日志到剪贴板。
  • 清屏与重跑：任务结束后点击「清屏」重置控制台，或点击「重新运行」再次执行上次任务。
