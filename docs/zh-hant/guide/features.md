# 核心功能

KernelEX 為 Android 底層極客與腳本開發者量身打造，涵蓋了執行引擎、流式緩衝、檔案管理與個人化介面的全方位體驗。

---

## ⚡ 1. 原生雙模執行與環境裝載

- **支援格式**：原生支援 Linux Shell 腳本（`.sh`）與 ELF 二進位執行檔（`.so`）。
- **標準環境變數注入**：任務啟動時自動預置核心路徑，避免因找不到系統命令而報錯：
  ```bash
  export PATH=/sbin:/system/sbin:/system/bin:/system/xbin:$PATH
  export TERM=xterm-256color
  export LANG=en_US.UTF-8
  ```
- **權限自動化**：執行前自動呼叫 `chmod 777` 賦予滿權，確保無執行權限障礙。
- **生命週期追蹤**：精確監控行程原生 PID 與返回的結束碼（Exit Code）。

---

## 🌊 2. 16ms 批處理流控與記憶體保護

- **16ms 幀同步防抖**：針對產生海量高頻日誌的腳本（如編譯輸出、抓包抓日誌、刷寫過程），日誌先進入並發佇列，按 16ms 週期聚合重新整理，避免 Compose 頻繁 Recomposition 導致的掉幀卡頓。
- **滑動視窗記憶體熔斷**：控制台文本上限設為 250,000 字元。超出時自動以換行符號為界滑動截取後 180,000 字元，記憶體平穩恆定，杜絕長任務 OOM。
- **ANSI 文本著色**：內建正規表示式與狀態解析機，支援標準 16 色與加粗高亮渲染。

---

## 📁 3. 全盤 ROOT 檔案管理

- **直通核心工作區**：預設工作目錄設在 `/data/adb/KernelEX`，適配主流 Magisk / KSU / APatch 工作流。
- **獨立資料夾儲存隔離**：開啟「使用獨立資料夾儲存」後，新增腳本時會自動建立帶時間戳的專屬子資料夾，防止多個同名腳本或依賴資源互相覆蓋衝突。
- **字型檔案預覽與熱替換**：在檔案管理器中點擊任意 `.ttf` / `.otf` 檔案即可即時預覽字型效果，支援一鍵設定為全域軟體字型。
- **安全防注入防護**：底層 Shell 執行路徑全量單引號轉義（`replace("'", "'\\''")`），重命名過濾 `..` 與特殊分隔符號，防止路徑穿越。

---

## 🎨 4. MIUIX 質感與個人化系統

- **雙主題支援**：在「設定」中可自由選擇 **MIUIX (HyperOS 擬物與通透質感)** 或 **Material 3** 設計語言。
- **懸浮 Dock 欄**：MIUIX 模式下可開啟底欄懸浮膠囊樣式，搭配流暢的 Spring 彈簧動效。
- **HSV 調色盤**：內建 16 種極客預設配色（螢光綠、黑客綠、賽博青、電光藍等），支援滑動色相環與明暗滑塊精確調節終端文字色彩。
