Features

⚡

Dual-Mode Native Execution

Native support for .sh Shell scripts and .so ELF binaries. Automatically injects standard Linux environments and sets 777 permissions.

🌊

16ms Smooth Flow & OOM Protection

Micro-batch queuing ensures buttery-smooth 60 FPS scrolling. Intelligent sliding-window truncation prevents OOM crashes from huge logs.

📁

Full ROOT File Manager

Direct access to the /data/adb/KernelEX workspace. Supports full-disk browsing, isolated timestamped directories, and live font previews.

🎨

MIUIX & Custom Color Wheel

Seamless switching between MIUIX (HyperOS) and Material 3 themes. Includes 16 geeky presets and a full HSV color wheel.
